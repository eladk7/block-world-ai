# חלק ד׳ – ממשק משתמש (20 נקודות)

## הפעלה
1. התקינו Python 3.10 ומעלה.
2. בתיקיית הפרויקט הריצו: `python -m pip install -r requirements.txt`.
3. הריצו: `python -m streamlit run app.py`.
4. פתחו את הכתובת המקומית המוצגת במסוף (בדרך כלל http://localhost:8501).

## שימוש
- הזינו מצב התחלה ומצב יעד: כל ערימה מופרדת בסימן `|`; קוביות בערימה מופרדות בפסיק בסדר מלמטה למעלה.
- בחרו A* או IDA* ויוריסטיקה h0, h1 או h2.
- הגדירו מגבלת זמן ומגבלת מספר פיתוחים; הפעילו חיפוש.
- בעת חיפוש מתמשך, לחצו Stop לשליחת בקשת ביטול.
- לאחר הצלחה יוצגו העלות האופטימלית, רצף ההזזות, המקור, היעד והעלות המצטברת.
- השתמשו בסרגל הצעדים ובכפתורים כדי לצפות במצבי הביניים.
- ביומן A* מוצגים מצבים שנשלפו מתור העדיפויות, ערכי g,h,f, גודל תור, הפעולה שהובילה למצב ומצב כל יורש.
- ביומן IDA* מוצגים ספי האיטרציות, פיתוחים וגיזומים, סף הבא ואירועי חיפוש.
- אפשר להוריד פלט ריצה כ־TXT ויומן מפורט כ־JSON לצורך תיעוד.

## מדדים
המערכת מציגה זמן ריצה, מצבים שנוצרו לפני הסרת כפילויות, מצבים שפותחו, מספר שיפורי מסלול ומספר איטרציות IDA*. ב־A* מוצג גודל תור העדיפויות המרבי; ב־IDA* מוצג עומק מחסנית DFS (המדדים אינם בני־השוואה ישירה).

## מגבלות
- עצירה יזומה היא בקשה לביטול בשיתוף פעולה מצד פונקציית החיפוש; היא אינה הריגה כפויה של תהליך Python.
- עבור קלטים גדולים ניתן להגיע למגבלת זמן או פיתוחים. המערכת מבדילה בין מגבלה לבין כשל למציאת פתרון.
- יומן החיפוש עשוי להיות גדול; ניתן לשמור אותו כקובץ JSON.
- אין צורך לפרסם את הממשק באינטרנט לצורך המטלה.

## תיעוד מומלץ ל־Word
הוסיפו תחת "חלק ד׳" צילום מסך של המסך לאחר פתרון דוגמת המרצה וצילום מסך של יומן החיפוש. הסבירו במשפט שהממשק מאפשר בחירת מצב התחלתי ויעד, אלגוריתם ויוריסטיקה, דפדוף במצבי פתרון, עיון ביומן והורדת פלטים.
